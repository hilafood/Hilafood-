# هیلا فود
فروشگاه فارسی RTL هیلا فود با تمرکز بر غذاهای فراسودمند و محصولات نیمه‌آماده.

- تصاویر محصولات در `assets/`
- تصاویر دسته‌بندی در `category/`
- اگر محصولی تصویر نداشته باشد، تصویر تکراری برای آن استفاده نمی‌شود و جای‌نگهدار نمایش داده می‌شود.
- دسته‌بندی محصولات عمداً در مدیریت دستی است.
- دسته «سالمندان» با عنوان **پک مامانجون و باباجون** نمایش داده می‌شود.
- موسیقی سایت حذف شده است.
